# Week 5 Assignment: Password Generator & Your Own Module

- `password_generator.py` creates random passwords using Python's `random` and `string` modules.
- `helpers.py` defines `tables_needed()` and `welcome()` and shows how `__main__` works.
- `main.py` imports `helpers` and calls its functions.

Run `password_generator.py` twice to see new passwords, then run `main.py` and `helpers.py` separately to compare their output.
